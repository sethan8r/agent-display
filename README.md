# agent-display

Shows the status of every running Claude Code session on a small ESP32 touch display
(ESP32-2432S028 "Cheap Yellow Display"): working, done, waiting for approval, waiting for subagents,
context usage and plan limits.

Work in progress.

## Install the plugin

In Claude Code:

```
/plugin marketplace add sethan8r/agent-display
/plugin install agent-display@agent-display
```
