# agent-display

Сенсорный дисплей ESP32 CYD, который показывает статусы всех запущенных сессий Claude Code на компьютере.
Цепочка: хуки плагина → хаб (Python, фон, единственный владелец COM-порта) → USB Serial, JSON Lines → плата (LVGL).
Формат обмена — `docs/protocol.md`, экраны — интерактивный макет `design/index.html`, установка — README.

**Версия 1.0.0, работает целиком.** Установка по README проверена с нуля 2026-10-25 (плагин с GitHub + новая
плата с заводской прошивкой, прошитая `/agent-display:update-firmware`). Порядок установки и прошивку не трогать без причины.

## Главные правила

- Плагин **никогда** не тормозит и не ломает Claude Code: хуки короткие, ошибки глотаются.
- Чужую статус-строку не ломать: обёртка выводит её без изменений.
- NVS на плате писать только при изменениях (износ flash).

## Окружение

- Python только через `py -3`: `python` в PATH — нерабочая заглушка Microsoft Store.
- PlatformIO: `~\.platformio\penv\Scripts\pio.exe`. Плата на **COM5**, только через **micro-USB** (по USB-C Windows её не видит).
- **Плагин у меня — dev-сборка**: marketplace на папку проекта, плагин читается прямо из `plugin/`. Правки хуков и
  команд — после `/reload-plugins` или в новой сессии; правки хаба — после перезапуска (погасить процесс `hub.py`,
  следующий хук поднимет новый). Пока хаб держит порт, `pio run -t upload` не пройдёт.
- Моя статус-строка обёрнута нашей обёрткой; исходная (`cc-usage-monitor`) сохранена в
  `~/.claude/agent-display/statusline.json`. Там же `hub.log`.

## Релиз

Поднять `FW_VERSION` в `firmware/src/app/model.h` и `version` в `plugin/.claude-plugin/plugin.json` →
`py -3 firmware/tools/publish.py` (собирает прошивку в `plugin/firmware/`) → тесты (`py -3 -m unittest discover plugin/tests`)
→ коммит → push. Без нового номера версии `claude plugin update` у пользователей ничего не скачает.

## Неочевидное (наступали)

- Отказ в разрешении и Esc не дают ни одного хука — хаб смотрит конец transcript.
- Невыровненный буфер LVGL молча отвергается → чёрный экран (`alignas(LV_DRAW_BUF_ALIGN)`).
- Значки нельзя мешать с текстом через fallback шрифта: у Inter свои глифы на тех же кодах. Значок — отдельная подпись.
- TinyTTF на плате падает по памяти → шрифты заранее отрисованы в bitmap (`firmware/tools/gen_fonts.py`);
  `npx lv_font_conv` заблокирован фильтром безопасности.
